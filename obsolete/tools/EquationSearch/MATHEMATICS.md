# Поиск рациональных точек через опорные точки

Это обоснование реализованных преобразований и постановка эксперимента.
Нового общего быстрого алгоритма вычисления ранга здесь не заявляется.

## 1. Начальный поиск только из уравнения

Пусть задана невырожденная интегральная модель

\[
y^2+a_1xy+a_3y=x^3+a_2x^2+a_4x+a_6.
\]

Положим \(b_2=a_1^2+4a_2\), \(b_4=a_1a_3+2a_4\),
\(b_6=a_3^2+4a_6\). Рациональная точка интегральной модели имеет вид
\(x=n/d^2,\ y=m/d^3\), где \(d>0\), \(\gcd(n,d)=1\).
Подстановка даёт точное условие:

\[
z^2=4n^3+b_2n^2d^2+2b_4nd^4+b_6d^6,
\qquad z=2m+a_1nd+a_3d^3.
\]

Алгоритм перебирает ограниченные \(n,d\), исключает отрицательные правые части
и неквадраты по модулям 16, 9, 5, 7, 11, затем проверяет целый квадрат точно.
Ни один из этих фильтров не исключает квадрат. Проверка чётности восстанавливает
целый \(m\). Знак можно нормировать, поскольку \(P\) и \(-P\) дают одинаковый
вклад в ранг. Минимизация модели и обратный перенос точки проверяются точно.

В `geometry.small_points` этот поиск ограничен. Увеличение обеих границ
в теоретической версии исчерпывает рациональные точки с точностью до знака.
Полнота перебора не является оценкой его практической скорости.
Для более сложных уравнений `bootstrap.py` также использует сдвиги, изменения
масштаба, редукцию моделей и кандидатов из делителей коэффициента \(b_6\).

## 2. Что именно даёт одна опорная точка

Перейдём к \(V=2y+a_1x+a_3\):

\[
V^2=f(x)=4x^3+b_2x^2+2b_4x+b_6.
\]

Пусть \(P=(x_0,v_0)\) — известная рациональная точка в этих координатах.
Подставим прямую \(V=v_0+t(x-x_0)\) и сократим известный корень \(x-x_0\).
Для \(u=x-x_0\) остаётся квадратное уравнение:

\[
4u^2+(12x_0+b_2-t^2)u+f'(x_0)-2v_0t=0.
\]

Его дискриминант задаёт кварту:

\[
z^2=D_P(t)=t^4-2(12x_0+b_2)t^2+32v_0t
             +b_2^2-8b_2x_0-48x_0^2-32b_4.
\]

Обратное отображение:

\[
x=\frac{t^2-b_2-4x_0+z}{8},\qquad
y=\frac{v_0+t(x-x_0)-a_1x-a_3}{2}.
\]

**Утверждение.** Любая рациональная точка \(Q\) с \(x(Q)\ne x_0\) получается
этим отображением. Действительно, возьмём рациональный наклон
\(t=(V(Q)-v_0)/(x(Q)-x_0)\) и
\(z=8x(Q)-t^2+b_2+4x_0\). Подстановка даёт \(z^2=D_P(t)\),
а обратные формулы возвращают \(Q\).
Исключительные точки \(P,-P,O\) уже известны и обрабатываются отдельно.

Следовательно, для алгебраической представимости не нужны 17 независимых
опор. Достаточно одной конечной рациональной точки. Это бирациональная
модель той же кривой; построение набора элементов группы Сельмера не требуется.
Рациональная точка на квартe всё ещё должна быть найдена поиском.

Две точки, соответствующие \((t,z)\) и \((t,-z)\), удовлетворяют
\(P+Q+R=O\). Если \(P\) уже в известной подгруппе, такая пара может добавить
не более одного независимого направления. Этот факт и обратные формулы
проверяются точной арифметикой в `test_search.py`.

## 3. Расширение и его границы

Сохраняем набор точек с доказанной независимостью. Из него строим опоры,
редуцируем соответствующие кварты, ищем рациональные решения в ограниченных
областях и сохраняем точки, увеличившие доказанную нижнюю границу.
После прибавки можем перестроить опоры.

Изменение опоры меняет размеры координат и коэффициентов задачи поиска.
Одна опора уже обеспечивает представимость; дополнительные опоры нужны для
эффективности. Нет доказательства, что очередная независимая точка всегда
имеет малые координаты хотя бы в одной из выбранных моделей.

Это **не насыщение в обычном смысле**. Для подгруппы \(H\)
\(H^{sat}=\{Q: mQ\in H\text{ для некоторого }m>0\}\) имеет тот же ранг, что
и \(H\), поскольку их линейные оболочки над \(\mathbb Q\) совпадают.
Увеличение ранга требует точки вне \(H\otimes\mathbb Q\).

Проверка независимости использует локальные 2-Куммеровы характеры и точную
линейную алгебру над \(\mathbb F_2\). Полный 2-спуск, группа Сельмера и
аналитический ранг не вычисляются; утверждать отсутствие любой связи
с 2-спуском было бы неверно. Текущий выбор базиса консервативен при рациональном
2-кручении. Неудача сертификатора сама по себе не доказывает зависимость.

В идеализированной версии для кривых без рационального 2-кручения можно
честно чередовать растущие области рационального поиска и растущие наборы
хороших простых. Сохраняя все наблюдения, при ранге не меньше заданного \(r\)
такая процедура в конце концов найдёт и сертифицирует \(r\) точек: конечный
набор независимых классов по модулю 2 попадёт в перебор, а достаточно много
локальных характеров разделят его (Cremona, lemma 2.1).
Это полуалгоритм без полезной общей оценки времени. При ранге меньше цели
он может не остановиться. Наш ограниченный по времени код этой гарантии
остановки не имеет.

## 4. Эксперимент

Первый набор: по одной кривой с каждой опубликованной границей 2..15,
первая строка таблицы ICARM по возрастанию проводника. Выбор фиксировался до
запусков. После пилота аналогично выбран второй набор с границами 16..20.
Из API сохранены только коэффициенты и метаданные выбора; опубликованные
координаты не сохранены и не переданы поисковым процессам.

Для каждой кривой первая независимая точка ищется из уравнения. Затем
отдельные процессы получают ровно одну эту точку. Сравниваются:

* `direct`: поиск на минимальной кубической модели без опоры;
* `fixed`: одна неизменная опора, без добавления новых опор;
* `adaptive`: опоры из уже найденных точек, перестройка после прибавок.

Опубликованное число используется только как цель остановки, а не как
сертификат. Каждый достигнутый положительный результат проверяется точно.
Совпадение координат с опубликованным списком не требуется и не заявляется.
Равенство достигнутой и опубликованной нижних границ не доказывает полный ранг.

Пилоты выполняются на одном компьютере с параллельными задачами. Время
первичного поиска и расширения записано отдельно. Это разведочный эксперимент,
а не универсальная оценка ускорения. Тайм-аут задания не означает, что область
поиска исчерпана. Сравнение с прямым поиском относится именно к записанной
реализации и её ограничениям, а не ко всем существующим алгоритмам.

Результаты 14 сентября 2026 года сохранены в `experiments.json`:

| Выбранные кривые | Прямой поиск | Одна фиксированная опора | Адаптивные опоры |
|---|---:|---:|---:|
| По одной с границами 2..17 | Все цели достигнуты | Все цели достигнуты | Все цели достигнуты |
| #644, цель 18 | 3 | 18 | 18 |
| #718, цель 19 | 0 найденных независимых точек | Не запускался: нет начальной точки | Не запускался |
| #631, цель 20 | 0 найденных независимых точек | Не запускался: нет начальной точки | Не запускался |

Для #644 первый поиск дал ровно одну наблюдённую точку
`(194856332260, -17165262408001720)`. Три последовательных повтора с одним
вычислительным работником дали 0 → 1 → 18 за 1.59–1.60 с, включая запуск
процессов и сертификацию. Сумма времени внутри двух этапов — 1.45–1.46 с.
Прямой контрольный поиск дошёл до 3 за 20.46–20.48 с; его конечная очередь
заданий исчерпалась, часть заданий завершилась по тайм-ауту.

У фиксированной опоры на #644 наблюдался переход 1 → 17 → 18 при расширении
областей поиска. Адаптивный режим достиг 18 в первом пакете моделей от P, 2P,
3P. Поэтому эти данные подтверждают пользу опорных моделей, но ещё не доказывают
преимущество многократной перестройки после появления новых независимых точек.
На простых кривых прямой поиск оказался быстрее.

В обоих наборах нет новых рекордов: воспроизведены нижние границы известных
кривых. Проверены 80 положительных сертификатов на Python и C#, а также 408
точных тождеств проекции и группового закона. Выборки небольшие и неслучайные.
